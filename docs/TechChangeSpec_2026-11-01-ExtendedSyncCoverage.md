# 工作区与资源增量同步补齐（3.1.8 / 202）

本次在既有会话、助手、提供商、偏好、记忆与媒体创作同步之上，增加工作区配置、完整技能目录、受管资源、界面偏好、翻译历史、用量流水、旧版生图记录、文件索引和记忆整理进度。

- 本地工作区仅同步名称、类型、工具审批等配置；不传输工作区文件、Linux 环境、安装状态、兼容模式、设备路径或最近访问时间。远端删除配置保留本机工作区文件。
- SSH 同步连接参数、主机指纹、密码、私钥和私钥口令；发送前由本机解密，接收后使用接收设备 Keystore 重新加密。同步服务保存可还原的凭据，浏览器设置和冲突预览继续脱敏。
- 技能以整个目录的资源清单同步，包括脚本、引用和嵌套资源；字节通过不可变内容寻址 blob 传输，全部下载校验完成后再替换目录。普通资源仅扫描 upload、media_creation、fonts、avatar、images，不扫描工作区。
- 尚未下载的清单保留在 Room，不当作本机删除；技能尚未落地时保留启用绑定。附件缺失保留重试，后续同步可以补齐。下载期间的本地编辑保存到冲突副本。
- 使用稳定同步 ID 区分用量和旧生图记录，接收时映射到本机自增主键。33→34 使用显式 Room 迁移，为历史记录回填稳定 ID，新增资源落地表。
- 自动裁剪的翻译历史和缺失文件的索引清理不广播删除；用户主动删除生成同步墓碑。记忆整理进度只有在消息分支前缀一致时才应用，避免跳过未整理消息。
- 扩展实体沿用 Sync V2 修订、Outbox、幂等及双副本冲突机制；新版客户端要求服务端声明完整扩展能力。升级时重新对账，补齐旧版遗漏内容。

验证通过 GitHub CI 执行 Android 编译、同步单元测试和三变体 ARM 发布包构建；本机仅运行后端测试、静态检查与安装包校验。发布矩阵为 github / coexist / coexistNormal × armeabi-v7a / arm64-v8a / universal，共九包。
